This project is a full-stack To-Do List application. The backend is built with FastAPI (Python) and uses SQLite as the database via SQLAlchemy ORM. It supports full CRUD operations — create, read, update, and delete todos — with filtering by priority, completion status, and search. Pydantic handles all data validation automatically. The frontend is plain HTML, CSS, and JavaScript that connects to the API using the Fetch API. Auto-generated Swagger docs are available at /docs.
